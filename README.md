# 렌즈로 여는 탐구 질문 (4차시)

「질문하는 힘 기르기」 4차시용 웹앱이에요. **학생 한 명이 태블릿 한 대**로 혼자 활동해요. (모둠 활동이 아니에요)

학생 화면 처음에는 버튼이 두 개 있어요.

1. **렌즈를 통해 질문하기**: 렌즈마다 다른 질문 틀을 살펴보고, 연습 그림을 보며 질문을 만들어 연습해요.
   - 질문 틀을 누르면 쓰기 칸에 틀이 들어가고 ○○ 자리가 골라져요. 바로 바꿔 쓰면 질문이 돼요.
   - 연습 질문은 이 태블릿에만 남아요. 마음에 드는 질문은 「프로젝트 질문으로」 보낼 수 있어요.
2. **프로젝트 탐구 질문 만들기**: 선생님이 올린 자료를 보며 내 질문을 써요.
   - 렌즈는 **골라도 되고 안 골라도 돼요.** 렌즈를 고르면 그 렌즈의 질문 틀이 옆에 떠요.
   - 쓰는 대로 저절로 저장돼요. 고치기와 지우기를 할 수 있고, 한 명이 20개까지 쓸 수 있어요.
   - **친구 질문은 보이지 않아요.** 활동이 끝난 뒤 선생님 화면에서 함께 봐요.

선생님이 **활동 종료**를 누르면 (제한 시간은 없어요) 모든 질문이 **우리 반 탐구 질문 보드**에 모여요. 그다음 **프로젝트 탐구 질문** 화면에서 「개념적 렌즈 - 탐구 질문」을 한 쌍씩 정리해요.

- **선생님은 준비할 것이 없어요.** 4차시 전용 서버 하나를 모든 반이 함께 써요. (1~3차시 서버와 따로예요)
- 화면은 노트북 · 전자칠판(선생님)과 태블릿 가로 · 세로(학생)에 맞췄어요.
- 빌드 도구 없는 정적 웹사이트예요. GitHub Pages에 올리면 바로 써요.
- 디자인(글꼴, 색, 고양이 궁금이)은 1~3차시와 같아요.

## 개념적 렌즈 8가지

| 렌즈 | 질문 틀 | 예시 (주제: 쓰레기) |
| --- | --- | --- |
| 형태 | ○○은 어떻게 생겼을까? / ○○은 어떤 특징이 있을까? | 우리 반에서 나오는 쓰레기에는 어떤 특징이 있을까? |
| 기능 | ○○은 어떻게 작동할까? / ○○은 어떤 쓰임이 있을까? | 재활용은 어떻게 작동할까? |
| 인과관계 | ○○의 이유는 무엇일까? / ○○ 때문에 어떤 일이 생길까? | 쓰레기가 계속 늘어나면 어떤 일이 생길까? |
| 변화 | ○○은 어떻게 변했을까? / ○○은 앞으로 어떻게 변할까? | 쓰레기를 버리는 방법은 예전과 어떻게 변했을까? |
| 연결성 | ○○은 무엇과 관련 있을까? / ○○과 △△은 어떻게 관련되어 있을까? | 쓰레기는 우리의 물건 사는 습관과 어떻게 관련되어 있을까? |
| 관점 | ○○에 대한 다른 관점은 무엇일까? / △△의 관점에서는 ○○을 어떻게 생각할까? | 환경미화원의 관점에서는 쓰레기 문제를 어떻게 생각할까? |
| 책임 | ○○을 위해 우리는 무엇을 해야 할까? / ○○에서 누구에게 어떤 역할(의무)이 있을까? | 쓰레기를 줄이기 위해 우리는 무엇을 해야 할까? |
| 정체성 | ○○을 ○○답게 만드는 것은 무엇일까? / 나(우리)에게 ○○은 어떤 의미일까? | 나에게 환경 보호는 어떤 의미일까? |

- 렌즈마다 한 줄 뜻과 색이 있어요. 내용은 `js/lenses.js` 한 파일에서 고쳐요.
- 선생님은 준비 화면에서 **렌즈를 추가**(이름 · 뜻 · 질문 틀 1~2개 · 예시)하거나 이번 수업에 쓰지 않을 렌즈를 **숨길** 수 있어요.
- 추가한 렌즈와 숨긴 렌즈는 그 컴퓨터에 기억돼서 다음 게임에도 그대로 써요.
- 연습 그림은 1차시 그림 3장이 기본이에요. 선생님이 5장까지 더할 수 있어요.

## 선생님 화면

| 단계 | 하는 일 |
| --- | --- |
| 준비 | 프로젝트 이름 · 한 줄 소개, **자료 올리기**, 렌즈 보이기·숨기기·추가, 연습 그림 고르기·추가 → **게임 코드 만들기** |
| 진행 (전자칠판) | **자료 보기**(한 장씩 크게, 넘기기, 화면 가득 **크게 띄우기**), **렌즈 안내판**, 게임 코드 · QR, 학생별 입장 · 질문 수 (질문 내용은 보이지 않음), **활동 종료** |
| 우리 반 질문 보드 | 모든 질문 카드 · 렌즈별 묶음 상자로 시작 → 끌어 옮기기, 눌러서 여러 장 고르기, **묶음 상자**, **하나로 합치기**, **렌즈 붙이기**, 고치기, 별표, 지우기(되살리기), 되돌리기, 이름 보이기·숨기기, 렌즈·별표로 보기, 확대·축소 · 상자 크게 보기 |
| 프로젝트 탐구 질문 | 「개념적 렌즈 → 탐구 질문」 칸 (기본 3칸 · 더하기 · 지우기 · 순서 바꾸기). 왼쪽 질문을 끌어다 놓거나 눌러서 넣고, 문장을 다듬어요 |
| 저장 | 프로젝트 탐구 질문 **그림(PNG) · 인쇄 · CSV**, 보드 **그림(PNG)**, 모든 질문 **CSV** |

- 보드는 서버에 저절로 저장돼요. 새로고침하거나 다른 날 같은 컴퓨터에서 이어서 열어도 그대로예요. (하루 안에)
- 활동을 끝낸 뒤 **다시 열기**를 누르면 학생들이 다시 질문을 쓸 수 있어요. 새로 쓴 질문은 보드의 「새로 들어온 질문」 상자에 들어와요.
- 보드 조작: 마우스 휠로 크게/작게, 빈 곳을 끌면 보드가 움직여요. 전자칠판 · 태블릿에서는 두 손가락으로 크게/작게 해요. `Ctrl+Z`는 되돌리기, `Delete`는 고른 카드 지우기예요.

### 올릴 수 있는 자료

| 자료 | 방법 |
| --- | --- |
| 글 | 직접 써요 (3000자까지, 빈 줄로 문단 나누기) |
| 이미지 | 파일 고르기 (여러 장 한꺼번에) · 태블릿에서는 카메라로 찍기. 올릴 때 저절로 줄여요 |
| PDF | 파일 고르기 → 쪽마다 그림으로 바꿔 저장 (10쪽까지) |
| 표 | 엑셀 · 구글 시트에서 복사해 붙여 넣기, 또는 CSV 파일 (30줄 · 8칸까지) |
| 영상 링크 | 유튜브 · 구글 드라이브 · 비메오는 화면 안에서 재생, 그 밖의 주소는 새 창으로 열기 |
| 링크 | 주소 + 설명 → 새 창으로 열기 |

- 자료는 20개까지, 그림(이미지 · PDF 쪽 · 추가 연습 그림)은 모두 30장까지 올릴 수 있어요.
- 만들던 자료는 그 컴퓨터에 저장돼서 새로고침해도 남아요. 다음 수업에 같은 자료로 다시 게임을 만들 수도 있어요. (지우려면 「새로 시작하기」)
- 영상 파일은 직접 올릴 수 없어요. 유튜브나 구글 드라이브에 올린 뒤 링크를 넣어 주세요. 학교에서 유튜브가 막혀 있으면 태블릿에서 영상이 안 보일 수 있어요. 이때는 선생님 화면에서 크게 띄워 함께 봐요.

## 내려받는 CSV

**프로젝트 탐구 질문**: `순서, 개념적 렌즈, 탐구 질문, 가져온 학생 질문, 프로젝트`

**모든 질문**: `번호, 별명, 학생 질문, 보드에서 고친 질문, 학생이 고른 렌즈, 보드 렌즈, 묶음, 합친 곳, 별표, 지움, 자료, 쓴 시각`

엑셀에서 바로 열려요. (UTF-8 BOM)

## 서버

| | |
| --- | --- |
| 서버 | 4차시 전용 구글 시트 + Apps Script 웹 앱 하나 (`js/config.js`의 `SERVER_URL`) |
| 선생님 구별 | 브라우저마다 만들어지는 선생님 열쇠. 게임은 만든 브라우저에서만 열고 지울 수 있어요 |
| 보관 기간 | 게임을 만든 뒤 **24시간**이 지나면 자료 · 질문 · 보드가 모두 지워져요 → 끝나면 내려받아 두세요 |
| 한도 | 선생님 한 분이 한꺼번에 게임 6개, 서버 전체 100개 · 게임 하나에 학생 60명 |
| 시트 | 「4차시 질문」 탭에 질문이 한 줄씩 쌓이고, 숨긴 「4차시 저장소」 탭에 자료 · 그림 · 보드가 들어가요 |

**연습 모드**: 서버 주소가 비어 있거나 선생님 화면에서 「인터넷 없이 이 컴퓨터에서 연습해 보기」를 누르면, 같은 서버 코드(`gas/Code.gs`)를 브라우저 안에서 돌려요. 「학생 창 열기」로 이 컴퓨터에 학생 창을 여러 개 띄워 미리 해 볼 수 있어요.

## 개발진이 할 일 (처음 한 번)

1. **서버 만들기**
   - 구글 드라이브 → 새 구글 시트(예: 「질문하는 힘 서버 (4차시)」)를 만들어요.
   - 확장 프로그램 → Apps Script → `Code.gs` 내용을 지우고 `gas/Code.gs`를 붙여 넣고 저장해요.
   - 함수 칸에서 `setup`을 골라 **실행** → 권한을 허용해요.
   - **배포 → 새 배포 → 웹 앱** (실행: 나 / 액세스: 모든 사용자) → 웹 앱 URL을 복사해요.
2. `js/config.js`의 `SERVER_URL`에 그 주소를 넣어요.
3. 저장소 `question-lens`를 GitHub Pages로 올려요. → `lona10048-hub.github.io/question-lens/`
4. 서버 코드를 고친 뒤에는 **배포 → 배포 관리 → 연필(수정) → 버전: 새 버전 → 배포**로 같은 주소를 유지해요.

## 시험해 본 것

- 서버 코드: 게임 만들기, 선생님 열쇠, 그림 조각 저장(시트 칸 나누기 · 수식 막기), 자료 설정, 입장(같은 별명 번호 붙이기 · 다시 들어오기), 질문 저장(다시 보내도 안전 · 고치기 · 지우기 · 20개 한도), 캐시가 지워졌을 때 시트에서 다시 읽기, 연결 풀기, 보드 저장, 활동 종료 직후 마지막 저장, 다시 열기, 하루 뒤 정리 (Node, 50가지)
- 화면: 연습 모드(선생님 1 + 학생 2창)로 자료 6종 올리기부터 보드 · 프로젝트 탐구 질문 · 내려받기 · 다시 열기까지 (41가지), 가짜 서버로 학생 30명 · 질문 114개, 다른 선생님이 남의 게임을 볼 수 없는지, 새로고침해도 이어지는지, 그림을 태블릿에 저장해 다시 받지 않는지, 노트북(1366×768 · 1440×900) · 태블릿(가로 1180×820, 세로 820×1180)

실제 서버를 배포한 뒤 **태블릿 두세 대로 한 번 해 보기**를 권해요.
